## Assets

All 3D geometries (biryani pot, steam particles, spice particles, clouds) are procedurally generated within the application using Three.js primitives. No external 3D models, textures, or image assets are used.

The favicon and all emoji icons used as category indicators are standard Unicode characters rendered natively by the browser.
